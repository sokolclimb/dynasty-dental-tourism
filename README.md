# Лендинг «Стоматологический туризм Москва → Рязань» — клиника «Династия»

Статический сайт без сборки: открывается двойным кликом по `index.html`.

## Что где менять (всё в `config.js`)
- `services` — услуги и цены (Москва / Династия), `qty: true` — можно выбрать количество.
- `pricesApproved` — поставьте `true`, когда утверждён прайс (уберёт пометку «демо-цены»).
- `offers` — акции, суммы, тексты. `tourism`, `doctors`, `reviews`, `faq` — контент.
- `clinic` — телефон, лицензия, ссылка на политику. `analytics` — ID Яндекс.Метрики / GA4.
- Фото кладите в `images/` и указывайте путь в `image` / `photo`.

## Заявки и КТ
- `formEndpoint: "send.php"` — почта + Telegram (настройте константы в `send.php`; PHP-хостинг).
- Либо webhook CRM/Make/n8n: укажите URL, придёт POST multipart/form-data с полями анкеты и `ctfile`.
- КТ сохраняется в папку вне публичной части сайта (`ct_private`), имя файла случайное. Нужен HTTPS.
- Без `formEndpoint` форма работает в демо-режиме (заявка пишется только в консоль браузера).

## Цели аналитики
`lead_submit`, `quiz_start`, `quiz_next`, `calc_select`, `cta_hero_calc`, `cta_hero_plan`, `cta_calc_personal`, `cta_offer_*`, `cta_sticky`, `click_phone`. Создайте их в Метрике как JS-события.

## Перед запуском
1. Утвердить прайс сравнения и условия акций (в ТЗ упомянуты две акции, перечислены три — оставлены все три).
2. Заменить заглушки (врачи, отзывы, фото, ссылки на экскурсии), оформить `privacy.html` юристом.
3. Проверить фирменные цвета/шрифт по dynasty62.ru (доступ к сайту из среды разработки не получен — палитра подобрана нейтральная, меняется в `:root` файла `styles.css`).
4. Выбрать канал заявок, подключить HTTPS, аналитику; добавить маркировку рекламы и лицензию.
